2. headings.ts — rewrite the scoring. Export `interface HeadingScoreParams`
   (the 9 keys above) and `DEFAULT_HEADING_PARAMS`.
   New signature: `analyzeHeadings(pages, brandTerms = [], params = DEFAULT_HEADING_PARAMS)`.

   Code constants (not DB params):
   - LEGAL_PATH = /impressum|datenschutz|privacy|agb|terms|cookie|legal|disclaimer|imprint|widerruf/i
     (tested against the URL pathname only)
   - GENERIC_HEADINGS = exact-match list, case-insensitive, trimmed:
     home, startseite, willkommen, welcome, mehr erfahren, weiterlesen, read more, kontakt, contact,
     news, aktuelles, menü, menu, navigation, suche, search, newsletter, unternehmen, produkte,
     leistungen, service, über uns, about us
   - TEMPLATE_SELECTOR = "header, nav, footer, aside"

   Heading extraction: as today (h1-h6, whitespace-collapsed text, skip empty). Per heading also
   record `inTemplate` = element has an ancestor matching TEMPLATE_SELECTOR.
   "Content headings" = headings with inTemplate === false, PLUS all H1 regardless of position.

   Per page:
   - h1Count = all non-empty H1 (unchanged definition)
   - excludedAsLegal = LEGAL_PATH matches the pathname
   - hierarchyIssue:
       null if the page has no content headings;
       "h1_not_first" if the page has >=1 H1 and the first content heading is not an H1;
       else "level_skip" if any content heading level is greater than the previous content heading
       level + 1;
       else null.
   - hasHierarchyIssues = hierarchyIssue !== null (keep this field; the current UI uses it)
   - h2Count = number of content H2
   - descriptiveShare = among content H1+H2: share whose text has >= quality_min_words words AND
     >= quality_min_chars characters AND is not in GENERIC_HEADINGS. 0 if there are none.
   - duplicateH1 = the page's first H1 text also appears as the first H1 on another scored page
     (case-insensitive).
   Component values per page (0..1). A page with ZERO headings gets 0 in all four components.
   - h1: 1 if h1Count === 1; multi_h1_credit if h1Count > 1; 0 if none
   - hierarchy: page has content headings and hierarchyIssue === null → 1, else 0
   - structure: h2Count >= min_h2_for_structure → 1, else 0
   - quality: descriptiveShare × (duplicateH1 ? duplicate_h1_factor : 1)

   Scored pages = pages with excludedAsLegal === false. If that set is empty, score all pages.
   Component average = mean over scored pages (0 if there are none).
   totalWeight = sum of the 4 weights.
   score = totalWeight > 0 ? round(Σ(avg_i × weight_i) / totalWeight × 100) : 0, clamped to 0..100.

   brandTerms: keep computing `keywordInHeadings` exactly as today, but it no longer affects the score.

   Return shape (keep all existing fields, add new ones):
   {
     score,
     pages: [{ url, h1Count, hasHierarchyIssues, hierarchyIssue, excludedAsLegal, h2Count,
               descriptiveShare (rounded to 2 decimals), duplicateH1, headings (first 20, as today) }],
     keywordInHeadings,
     scoredPageCount,
     breakdown: {
       h1: { avg, weight, points },
       hierarchy: { avg, weight, points },
       structure: { avg, weight, points },
       quality: { avg, weight, points }
     },
     params
   }
   where points = avg × weight / totalWeight × 100, rounded to 1 decimal.
