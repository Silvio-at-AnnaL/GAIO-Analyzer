The prefill crawl-failure diagnostics still report the generic message for www.affinis.de even though
that domain fails with an incomplete TLS chain. Root cause: in fetchHtml() the line
`if (!resp.ok) return null;` handles HTTP error statuses WITHOUT calling onError, and the classifier only
runs in the catch block (i.e. only when fetch THROWS). So any failure that arrives as a status rather than
a thrown error falls through to "unknown". This fix (a) also classifies HTTP-status failures, and
(b) adds temporary diagnostic logging so we can see, on Replit's actual runtime, whether the TLS error
arrives as a thrown exception or as a status. Do not touch report-export.ts. Do not touch any
image/binary asset files. Do not publish.

=== 1) artifacts/api-server/src/lib/fetch-diagnostics.ts ===
Add a new reason for HTTP error statuses to the union and a helper to classify a status code. Keep the
existing classifyFetchError() exactly as it is; ADD to the file:

    export type CrawlFailReason =
      | "tls_chain"
      | "tls_other"
      | "dns"
      | "refused"
      | "timeout"
      | "http_error"      // <-- NEW
      | "unknown";

    /** Server responded, but with a non-OK HTTP status (4xx/5xx). */
    export function classifyHttpStatus(status: number): CrawlFailReason {
      return "http_error";
    }

(Keep it a function rather than inlining, so we can refine per-status later if needed.)

    Replace the current body from the fetch call through the catch block with:

          headers: { "User-Agent": CRAWLER_UA, Accept: "text/html,application/xhtml+xml,*/*;q=0.8" },
          redirect: "follow",
        });
        if (!resp.ok) {
          const reason = classifyHttpStatus(resp.status);
          // TEMP DIAGNOSTIC — remove once affinis.de is confirmed working
          logger.warn({ url, status: resp.status, reason, kind: "status" }, "Prefill: fetch non-OK status");
          onError?.(reason);
          return null;
        }
        return await resp.text();
      } catch (err) {
        const reason = classifyFetchError(err);
        // TEMP DIAGNOSTIC — dump the full shape so we can see what Replit's Node actually throws
        const e = err as { name?: string; code?: string; message?: string; cause?: { code?: string; message?: string } };
        logger.warn(
          {
            url,
            reason,
            kind: "throw",
            errName: e?.name,
            errCode: e?.code,
            errMessage: e?.message,
            causeCode: e?.cause?.code,
            causeMessage: e?.cause?.message,
          },
          "Prefill: fetch threw",
        );
        onError?.(reason);
        return null;
      } finally {
        clearTimeout(timer);
      }
