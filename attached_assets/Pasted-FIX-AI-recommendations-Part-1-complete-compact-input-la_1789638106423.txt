FIX — AI recommendations, Part 1: complete compact input, language guard, time budget.
Backend only.

Context (verified):
recommendations.ts builds the AI input with
`JSON.stringify(moduleResults, null, 2).slice(0, 12000)`.
Measured for steinbach: headingStructure ≈ 25,000 chars, technicalSeo ≈ 12,100 chars.
So the AI regularly never sees schemaOrg / contentRelevance / faqQuality / llmDiscoverability,
and invents findings ("Strukturierte Daten vollständig fehlend" while schema score = 90).
Also, containsEnglish() matches substrings like "site " / "page " / "is ", which occur in German
words ("Website ", "Homepage ", "Hinweis "). This probably triggers a full second AI call almost
every time.
The prompt template lives in the DB (seeded with ON CONFLICT DO NOTHING), so the placeholder
{{RESULTS_JSON}} must stay. Only its CONTENT changes.

1. recommendation-input.ts: export `buildRecommendationInput(moduleResults: Record<string, unknown>): { text: string; size: number; modules: Record<string, "ok" | "missing">; trimLevel: number }`.
   Output = a short German header line followed by COMPACT JSON (JSON.stringify without indentation).
   Header, verbatim:
   "VERBINDLICHE MESSWERTE DER ANALYSE (vollständig, alle Module enthalten). Leite Befunde ausschließlich aus diesen Daten ab. Behaupte nie, etwas fehle, wenn die Daten es als vorhanden ausweisen. Module mit status \"nicht_verfuegbar\" wurden nicht gemessen – daraus keine Befunde ableiten."

   JSON object with exactly these top-level keys, in this order. Any module that is null/absent
   becomes { status: "nicht_verfuegbar" }.
   - crawl: { pagesAttempted, pagesSucceeded, pagesFailed } from moduleResults.crawlReliability
     (attempted/succeeded/failed)
   - technicalSeo:
     { score, httpsEnforced, mobileViewport, responseTimeMs, ttfbMs, canonicalTags, hreflang,
       metaTitles, metaDescriptions, imageAltCoverage, robotsTxt, sitemapXml, sitemapType, llmsTxt,
       robots: { summary, llmCrawlers (name+status), siteBlockedAgents } | null,
       sitemap: { summary, totalUrls, crawledPageCoverage } | null,
       llmsTxtInfo: { present, hasDescription, linkedPageCount, sectionCount, summary } }
     Do NOT include robotsTxtContent, sitemapXmlContent, llmsTxtContent, or llmsTxt sections/links.
   - schemaOrg:
     { score, detectedTypes, missingHighValue,
       typeBreakdown: [{ type, objectCount, substancePercent }],
       breadthScore, substanceScore, correctnessFactor, productSchemaDetails,
       validationErrors: first 5, each cut to 200 chars }
   - headingStructure:
     { score, pagesAnalysed, scoredPageCount,
       breakdown: { h1, hierarchy, structure, quality } each as { points, weight } rounded to 1 decimal
         (omit if absent),
       pagesWithoutH1, pagesWithMultipleH1, pagesWithHierarchyIssues
         (all three counted over pages with excludedAsLegal !== true),
       problemPages: max 10 [{ url, reasons }] where reasons ⊂
         ["keine H1", "mehrere H1", "H1 nicht erste Inhaltsüberschrift", "Ebene übersprungen", "H1 doppelt"],
       sampleH1: max 10 [{ url, h1 }] with the first H1 per page, cut to 120 chars,
       keywordInHeadings }
     Never include the full headings arrays.
   - contentRelevance: { score, dimensions: [{ name, score, findings: max 4, each cut to 300 chars }] }
   - faqQuality: { score, hasFaqSchema, hasHtmlFaq, faqItemsFound, qualityAssessment cut to 800 chars }
   - llmDiscoverability:
     { score, avgRating,
       partA: { label, score, avgRating }, partB: { label, score, avgRating },
       questions: max 12, lowest rating first,
         [{ question (≤200 chars), rating, gap (≤250 chars), sourceUrl }] }
   Size control: MAX_INPUT_CHARS = 30000 (named constant). If the text exceeds it, apply these
   trim levels one by one until it fits:
     1) drop sampleH1
     2) questions → max 6
     3) findings → max 2 per dimension, qualityAssessment → 400 chars
     4) problemPages → max 5, validationErrors → max 2
   NEVER drop a module and NEVER slice the final string. Return the trimLevel that was applied.
   All accessors must be defensive: unknown types → skip the field, never throw.
