BUGFIX — page title extraction counts inline SVG <title> elements. Backend only.

Confirmed bug:
technical-seo.ts line ~387 uses `$("title").text().trim()`, which CONCATENATES every <title> in the
document, including the <title> elements inside inline SVG icons (payment icons, social icons, etc.).
competitors.ts extractPageTitle() has the same flaw: its regex takes the FIRST <title> in the document,
which on such pages is an SVG icon title.
Measured against live sites:
  identbase.de/                      real "Startseite" (10 chars)                 measured 268
  identbase.de/de/kartendrucker.html real "Kartendrucker günstig kaufen | ..." (40) measured 213
  cards-x.de/                        no <title> in the served HTML                measured 88
  steinbach-kugellager.de/           real 44 chars                                measured 44 (correct)
Consequences: false "meta titles too long" findings, missing titles counted as present, and wrong page
titles in the competitor page list ("American Express" for cards-x.de).

Files in scope:
- NEW artifacts/api-server/src/lib/html-title.ts
- artifacts/api-server/src/lib/analyzers/technical-seo.ts
- artifacts/api-server/src/lib/analyzers/competitors.ts

1. html-title.ts — export two functions, no other logic:
   - `getTitleFromDom($: cheerio.CheerioAPI): string` —
       first try `$("head > title").first().text()`;
       if that is empty, take the first `<title>` that has NO <svg> ancestor
       (`$("title").filter((_, el) => $(el).parents("svg").length === 0).first().text()`);
       return the result with whitespace collapsed (\s+ → " ") and trimmed; "" if none.
   - `getTitleFromHtml(html: string): string` — load the html with cheerio and call getTitleFromDom.

2. technical-seo.ts: replace `$("title").text().trim()` with `getTitleFromDom($)`.
   Everything else (counters, thresholds, scoring) stays exactly as it is.

3. competitors.ts: replace the regex in extractPageTitle with getTitleFromHtml.
   Keep the function's signature and its null/empty handling as today
   (return null when the title is empty, so the UI behaves as before).
