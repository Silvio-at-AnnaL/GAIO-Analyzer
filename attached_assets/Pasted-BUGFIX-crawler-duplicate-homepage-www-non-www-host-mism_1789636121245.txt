BUGFIX — crawler: duplicate homepage + www/non-www host mismatch. Narrow scope. crawler.ts only.

File: artifacts/api-server/src/lib/crawler.ts (no other file).

Confirmed bugs (reproduced with the real crawler):
(1) crawlSite does `const homepageUrl = inputUrl; visited.add(homepageUrl);` without normalization.
    Links resolve to "https://host/" (URL.href always adds "/" for root), so for input "https://host"
    the homepage is crawled twice.
(2) baseDomain = hostname of the INPUT. If the input is "https://affinis.de", the site redirects to
    www.affinis.de and links absolutely to www. extractInternalLinks and parseSitemapUrls then drop
    every link as foreign → the crawl returns only the homepage (twice).

Required changes:
A. fetchWithTiming: also return `finalUrl: response.url || url`. Keep everything else identical,
   including the timeout/abort logic. Other callers may ignore the new field.

B. crawlSite — canonical origin:
   - hostKey(h) = h.toLowerCase().replace(/^www\./, "")
   - siteKey = hostKey(input hostname)
   - After the homepage fetch: if finalUrl parses AND hostKey(final hostname) === siteKey, then
     canonicalProtocol/canonicalHost = the final URL's protocol and host.
     Otherwise use the input's protocol and host. Cross-domain redirects keep today's behaviour.
     If the homepage fetch throws, use the input's.
   - canon(u): apply normalizeUrl(u); if its hostKey === siteKey, set protocol and host to the
     canonical ones; return href. On parse error return the input unchanged.

C. Apply canon consistently:
   - Before fetching: visited.add(canon(inputUrl)).
   - After fetching: also visited.add(canon(finalUrl)).
   - The homepage entry in result.pages uses url = canon(finalUrl) (or canon(inputUrl) if unavailable).
     Use the same URL for recordFailure and hreflang extraction of the homepage.
   - extractInternalLinks: compare hosts with hostKey(...) === siteKey instead of
     `hostname !== baseDomain`, and return canon(...)'d URLs. Pass siteKey and canon in as parameters.
     Keep all other filters: scoreUrl, isWithinStartPath, excludedUrls, seen.
   - parseSitemapUrls: same host comparison via hostKey, return canon(...)'d URLs.
   - hreflang: variant URLs added to hreflangUrlSet must be canon(...)'d, so they match queue entries.
     result.hreflangVariants may keep the original URLs for display.
   - discoverSitemap origin: use the canonical protocol/host once they are known.
     robots.txt and llms.txt stay as they are (fetched before the homepage; redirects are followed).
   - makeEntry/addToQueue: unchanged, but must only ever receive canon(...)'d URLs.
